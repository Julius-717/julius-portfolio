# Notes

Independent labs and articles. Each `.mdx` file here becomes `/notes/<filename>`.
The Notes link (footer, sitemap, About page) appears automatically once at least
one non-draft note exists.

Run `npm run check:confidential` before publishing. Lab work must come from your
own environments only.

---
title: "Finding IAM privilege-escalation paths: a read-only method"
summary: "One or two sentences shown on the listing and in search results."
date: 2027-01-15            # YYYY-MM-DD
kind: Lab                   # Lab | Article
tags: [AWS IAM, Python, Attack paths]
repo: https://github.com/Julius-717/<repo>   # optional
draft: true                 # remove when ready to publish
---
